# AI 時代職涯視覺報告｜Visual V2

純靜態網站，不需 Node.js 或任何外部套件。

## Netlify

解壓縮後，將整個資料夾拖入 Netlify 的 **Deploy manually**。

若連接 GitHub：Build command 留空，Publish directory 填 `.`。

## GitHub Pages

將全部檔案上傳到 Repository 根目錄，再到：

`Settings → Pages → Deploy from a branch → main → /(root)`

## 網頁操作

- `⚡ 10分鐘版`：隱藏次要說明，適合快速報告。
- `🎙 講者提示`：顯示教師補充說法。
- 五班按鈕：切換公廣、電影、電視、廣播與傳管版本。

## 檔案

- `index.html`：網頁、CSS 與互動程式。
- `assets/ai-experience-hero.webp`：原創主視覺。
- `netlify.toml`：Netlify 設定。
- `.nojekyll`：GitHub Pages 相容設定。
