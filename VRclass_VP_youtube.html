02 · JUNIOR / VR & XR

MR × ENGINE

Meta MR × UE5

WEB 3D

WebXR × Three.js

瀏覽器直接進 VR，搭配 WebXR Samples、Three.js、VRM，適合 Quest 與跨平台教學。

AVATAR

VTuber × Motion

VRM、VMC、Live Link、BlendShape、身體與臉部動作串接，形成即時 Avatar Pipeline。

SPACE

Projection Mapping

TouchDesigner + KantanMapper、360° AI 內容投影，把「虛擬場景」投到真實建築與空間。

PROTOTYPE

SCAN

大三主線：不是「學一堆 XR 工具」，而是讓學生能把 3D 資產 → 互動 → 空間體驗 → 展示，做成完整作品。
03 · GRADUATE / VIRTUAL PRODUCTION

研究所：從「後製合成」走到「拍攝現場就是合成系統」

🟡 傳統路線

Green Screen→Keying→Nuke→CG Composite

優點是後期控制最大；代價是「先拍再算」，燈光、反射、邊緣與溢色要靠後製救。

VS

🟢 Virtual Production 路線

VAD / UE5→nDisplay→Tracking→ICVFX / LED

把合成前移到拍攝現場，讓前景光影、反射與導演決策同步發生。

SYNC

nDisplay / Genlock

不是把 HDMI 插到 LED 牆就完成。場景需要分割、同步與多節點輸出，還要避免黑線與閃爍。

ICVFX CORE

Inner / Outer Frustum

鏡頭內視錐用高品質動態透視；外視錐主要負責環境光與反射，是 ICVFX 效率的核心。

COLOR

Color Pipeline

RAW / Log、OCIO、OpenVPCal、Rec.2020 / PQ、Creative LUT，並避免 Double Tone Mapping。

研究題目直接可以做 A/B Test：同一個 UE5 場景，分別走「綠幕＋Nuke」與「LED＋ICVFX」，比較時間、成本、邊緣品質、人物光影、色彩一致性與導演控制。
